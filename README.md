# analise-vendas-ecommerce
Projeto de análise de dados de um e-commerce utilizando Python, SQL, Estatística e Power BI.
## Sobre o projeto

Este projeto simula uma análise de dados realizada para uma empresa de comércio eletrônico. O objetivo é transformar dados de clientes, pedidos, produtos e pagamentos em informações úteis para apoiar decisões comerciais.

## Problema de negócio

A empresa possui um grande volume de dados de vendas, mas não consegue identificar com clareza quais produtos geram mais receita, quais regiões apresentam melhor desempenho, como o faturamento evolui ao longo do tempo e quais clientes possuem maior valor para o negócio.

## Objetivos

* Analisar a evolução do faturamento e da quantidade de pedidos.
* Calcular indicadores como ticket médio e valor médio por cliente.
* Identificar os produtos e as categorias mais vendidos.
* Comparar o desempenho das vendas entre estados e regiões.
* Identificar os clientes com maior volume de compras.
* Aplicar análises estatísticas aos dados de vendas.
* Construir um dashboard interativo para apoiar decisões comerciais.

## Tecnologias previstas

* Python
* Pandas
* SQL
* Estatística
* Power BI
* Git e GitHub
